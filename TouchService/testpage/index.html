    觸控模式
    （連線後載入面清單）
    觸點以整個場域 canvas 十字展開圖等比映射到螢幕；勾選的面才驅動游標（地板預設不勾——腳步會亂點）。
    投影沒滿版時校正用（letterbox）：落點 = 螢幕原點 + offset + norm × 螢幕寬高 × scale。滿版維持 0 / 0 / 1 / 1。
    0.35 1 = 不平滑直接到位
    px，平滑迴圈小於此位移不注入
    ⚠ 滑鼠模式下摸牆會搶這台機器的真實游標（鍵盤滑鼠同時操作會互相干擾）；發布端不受影響，監控頁/訂閱端照常收事件。

    疑似噪訊排行（GET /history，每 5 秒刷新）
    score 0–100 = 三個可解釋因子加權：30 分鐘觸發頻率（40）＋ 孤立觸發比率（35）＋ 活躍時長佔比（25）。 score ≥ 60 建議看一眼、≥ 80 高度可疑 （同格反覆觸發、無鄰近連動、長時間常駐叫——間歇型噪訊晶片的典型樣貌）。 分數只用來排序，不會自動鎖：營運中有真人在踩，誤鎖比漏鎖傷，鎖定請人工確認後按「鎖定」。 歷史為運行期統計、重啟歸零（刻意設計——可疑晶片會很快重新冒上排行）。

    校正精靈（新場域兩角校正）
    新場域（例：單面牆）不用手算校正值：填好面的格數 → 開始校正 → 依引導踩「左上角第一顆晶片」與「右下角最後一顆晶片」→ 精靈自動算出 rawMin/Max 與 flip → 儲存後重啟服務即生效。多面場域逐面累積（origin 手填， 進階說明見 docs/CALIBRATION.md）。校正期間服務照常發布，不影響營運。
    未開始 開始後 15 分鐘無動作自動結束；重按「開始校正」可延長。
